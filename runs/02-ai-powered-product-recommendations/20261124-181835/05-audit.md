# 5. Best-practice audit: 02-ai-powered-product-recommendations

**Verdict: pass_with_findings** (9 followed, 7 violated)

The sample is a runnable Node.js app that meets the starter-prompt functionality: it seeds products (10k) and orders (20k), creates a DiskANN vector index (dimensions 1536), stores embeddings, exposes an Express UI, implements per-session memory persisted in a 'sessions' collection, and returns the top-5 recommendations with textual reasoning (OpenAI when available, deterministic synthetic fallback otherwise). Key runtime checks (seed, index creation, a one-shot vector search) were executed against the live cluster. Findings: the builder intentionally did not use LlamaIndex (no adapter/skill/SDK used), embeddings are generated from product text (not directly from co-purchase aggregates), some production-grade practices (retries honoring Retry-After, idempotent seed/upserts and unique indexes, infrastructure-as-code, documented clean-up steps, and explicit index/query tuning guidance) are missing or only partly implemented. Many best-practices are implemented and traceable to installed skills (singleton client, env-driven config, DiskANN index, normalized embeddings, $search/cosmosSearch usage).
