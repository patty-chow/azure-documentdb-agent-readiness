# 5. Best-practice audit: 18-360-data-platform-cdp-orchestration

**Verdict: pass_with_findings** (6 followed, 5 violated, 1 not applicable, 4 not assessable)

The sample implements the requested Python + LangChain orchestration (ingest → dedupe → enrich) and runs end-to-end against the provided Azure DocumentDB cluster. Core behaviors are present and were exercised in the run: the app reads DOCUMENTDB_URI from the environment, uses a singleton MongoClient, seeds data idempotently, runs the pipeline and writes a workflow document. Major gaps: native vector-index creation failed in this run because management tools were disabled (tool error), so vector-search verification and vector-index tuning were not completed; several operational best-practices (retries/backoff, bulkWrite batching, TTL for workflow logs, explicit transaction usage for multi-document merges where atomicity is required) are absent. Tests are designed to run offline and are present. The report below lists per-requirement results, practice checks, decision reviews and recommended documentation/tooling fixes the product team should consider.
