# 5. Best-practice audit: 06-omnichannel-interaction-history

**Verdict: pass_with_findings** (10 followed, 4 violated, 1 not assessable)

The sample implements the core starter-prompt requirements: a Node.js + Mongoose service, a single interactions collection, the two compound indexes, a seed script that upserts idempotently, a cursor-based paginated history endpoint, and a channel-breakdown aggregation. The app reads DOCUMENTDB_URI from the environment and supplies .env.example. Verification steps (npm run seed, npm run test-queries) and a DocumentDB MCP index listing were performed against the live cluster. Findings: several gallery expectations beyond the prompt were omitted (no unit tests that run offline, no IaC for the cluster, missing projection on history queries, no explicit production autoIndex disabling and only minimal retry/backoff handling). A number of product-team best practices are present and discoverable; a few checklist items (driver pinning guidance, test guidance, IaC examples) are not documented or were hard to find and should be added to the public docs or agent kit.
