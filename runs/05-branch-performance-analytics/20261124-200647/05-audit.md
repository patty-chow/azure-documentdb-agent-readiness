# 5. Best-practice audit: 05-branch-performance-analytics

**Verdict: pass_with_findings** (7 followed, 10 violated, 3 not assessable)

The sample implements the requested FastAPI service, $facet aggregations, per-branch cached summaries and an /ask endpoint that composes cached summaries and calls OpenAI. The build verified seeding ~5k transactions, created indexes for the transactions collection, and wrote 10 branch summary documents to branch_summaries. Missing or partial items: the repository does not include a real LangChain dependency (the builder intentionally implemented a small LangChain-style tool because langchain install failed), vector/hybrid search and vector index creation are not implemented, a number of DocumentDB best-practice options (allowDiskUse, explicit retry/timeouts, TLS enforcement, some recommended indexes on branch_summaries) are not applied, tests require a live cluster (no offline mock tests), and no infra-as-code for mongoClusters is present. None of these omissions made the sample non-functional for the basic scenario the prompt asked for (aggregation, caching, NL tool fallback). The report below lists exact file/line evidence, the cause for each missing or partial requirement, the smallest fix to get it met next time, and documentation gaps the product team should fill so agents can find the guidance without human review.
