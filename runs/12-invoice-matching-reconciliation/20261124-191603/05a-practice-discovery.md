## Where public sources contradict the model

### P17: Azure DocumentDB supports multi-document transactions but with limits: multi-document (ACID) transactions are supported only within a single non-sharded collection (cross-collection and cross-shard transactions are not supported).

- **The model believed:** For reconciliations that update multiple documents (invoice flagged matched and PO annotated), use multi-document transactions (startSession + withTransaction) so the set of writes is consistent if the cluster supports MongoDB transactions. (knowledge of `mongodb`)
- **The source says:** Azure DocumentDB supports multi-document transactions but with limits: multi-document (ACID) transactions are supported only within a single non-sharded collection (cross-collection and cross-shard transactions are not supported).
- **Source:** [Use Multi-document transactions in Azure Cosmos DB for MongoDB](https://learn.microsoft.com/azure/cosmos-db/mongodb/use-multi-document-transactions)
