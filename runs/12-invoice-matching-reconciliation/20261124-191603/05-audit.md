# 5. Best-practice audit: 12-invoice-matching-reconciliation

**Verdict: pass_with_findings** (5 followed, 7 violated, 5 not assessable, 1 not applicable)

The sample implements the core invoice→PO reconciliation flow, uses Mongoose against the DocumentDB cluster, provides an LLM-backed extraction path (with a deterministic fallback), and keeps in-session corrections in memory. Key builder choices (OpenAI models, ephemeral session memory, Using OpenAI SDK rather than LangChain for LLM calls) are recorded and implemented. Verification steps (npm install, seed, one-shot reconcile) ran successfully against the live cluster. Major gaps: no vector-index creation or tuning, connection options/timeouts/retries are left at defaults, missing robust retry/error-handling for external calls, and there are no offline unit tests. The README and .env.example are present but clean-up and EntraID guidance are thin. See requirement_results and checks for details and exact file/line evidence.
