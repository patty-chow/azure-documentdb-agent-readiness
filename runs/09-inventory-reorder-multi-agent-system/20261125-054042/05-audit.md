# 5. Best-practice audit: 09-inventory-reorder-multi-agent-system

**Verdict: pass_with_findings** (11 followed, 8 violated, 2 not applicable)

The sample is a working Python LangChain-style multi-agent demo that exercises the forecast → supplier → orchestrator flow against a live Azure DocumentDB cluster. The code, seed script, tests, README and verification steps exist and were run as described. The build follows many DocumentDB best practices (singleton MongoClient, env-driven secrets, idempotent seed, indexes for query patterns, persisted agent memory with uniqueness to avoid duplicate POs). Remaining findings are mostly about omissions or hardening for production and about vector-search/index documentation and discoverability. None of the issues prevented the sample from running in this environment or produced an obviously insecure secret leak; however several recommended operational practices (timeouts, connection-pool tuning, explicit TLS enforcement in client options, Key Vault guidance, JSON-schema validators, vector-index creation) are missing and should be added before publishing the gallery sample.

Notes about tool availability: the run had documentation search available and many DocumentDB skills were loaded (events.jsonl shows the documentdb-* skills being loaded).
