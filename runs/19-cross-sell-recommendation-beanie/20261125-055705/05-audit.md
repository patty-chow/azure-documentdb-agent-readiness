# 5. Best-practice audit: 19-cross-sell-recommendation-beanie

**Verdict: pass_with_findings** (9 followed, 5 violated, 4 not applicable)

The sample implements the core cross-sell flow (async FastAPI + Beanie, seeding products/orders/pairs, storing normalized embeddings, a /cross-sell endpoint returning top-5 affinity-ranked candidates, pinned deps, .env.example, README, and unit tests that run without a live DB). Major gaps: the sample does not create the DocumentDB cosmosSearch vector index programmatically and it does not run a server-side $search / cosmosSearch vector query at request time (it scores candidates in-app using stored embeddings). Several checklist items that expect idempotent seed/index creation and server-side vector search are partly or not met. See requirement-by-requirement findings and practice checks below. Where the product team expects guidance but it wasn’t discoverable, I list documentation gaps and proposed fixes.
