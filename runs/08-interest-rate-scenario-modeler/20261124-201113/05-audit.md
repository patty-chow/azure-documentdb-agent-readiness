# 5. Best-practice audit: 08-interest-rate-scenario-modeler

**Verdict: pass_with_findings** (7 followed, 1 not assessable, 7 violated, 3 not applicable)

The sample implements the core requested functionality: a Python LangChain-based ScenarioAnalyzer that calls an aggregation helper which runs a MongoDB aggregation pipeline against an Azure DocumentDB cluster to group fixed and floating positions by maturity bucket. The seed script is idempotent and the singleton MongoClient pattern is implemented; unit tests passed. The LLM end-to-end run was not executed in the build (OPENAI_API_KEY absent), and a few gallery best-practices were only partly followed or omitted (notably: not exposing the aggregation as a LangChain Tool object, incomplete .env.example, unpinned dependency versions, index-creation placement and some operational hardening items). Several public best-practices exist and were discoverable (skills and Microsoft docs); a few discoverability/naming gaps remain that the product team should address (mongoClusters vs databaseAccounts, CLI group names, computed-field indexing guidance, idempotent index-creation docs). See requirement_results, checks, decision_reviews and doc_gaps below for details and exact file/line citations.
