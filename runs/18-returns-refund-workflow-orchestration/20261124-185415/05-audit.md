# 5. Best-practice audit: 18-returns-refund-workflow-orchestration

**Verdict: pass_with_findings** (13 followed, 7 violated)

The sample implements the requested end-to-end returns orchestration, runs the three agents in sequence, reads/writes Azure DocumentDB via Mongoose, includes an idempotent seed and demo, and defaults to deterministic mock LLM outputs so demos run without external LLMs. Key gallery hygiene items (search endpoint, offline unit tests, explicit retry/backoff, idempotent return creation, explicit projection usage, infra-as-code) are missing or partial. Several of these gaps are because the short starter prompt did not require them; a few arise from a runtime incompatibility with the langchain package which the builder worked around. See requirement-by-requirement results, practice checks, decision reviews, and suggested doc fixes below.
