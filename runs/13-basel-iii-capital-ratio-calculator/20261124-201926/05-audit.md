# 5. Best-practice audit: 13-basel-iii-capital-ratio-calculator

**Verdict: pass_with_findings** (7 followed, 7 violated, 1 not applicable, 1 not assessable)

The sample implements the requested Python LangChain agent pattern, a DocumentDB-backed aggregation pipeline that sums RWAs and capital elements, computes CET1 and Total Capital ratios, and produces a board-ready commentary. The repository runs on the live cluster (seed and aggregation were exercised in verification) and sensibly falls back to a deterministic commentary when OPENAI_API_KEY is absent. Key findings: the LangChain tool exposed to the LLM does not itself call the database (it returns precomputed aggregates), unit-tests and some runner scripts reference a non-existent class API, .env.example has a syntax problem, some “best-practice” guidance from the DocumentDB skills (pool tuning, Decimal128, explain()) was not followed, and there is no infra-as-code for cluster provisioning or monitoring instrumentation. None of the issues found make the sample unsafe to run against the provided cluster, but several developer- and agent-facing issues should be fixed before publishing.
