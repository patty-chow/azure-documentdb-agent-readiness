# 5. Best-practice audit: 01-anti-money-laundering-pattern-detector

**Verdict: pass_with_findings** (19 followed)

I read the sample under app/. A working Python sample is present: it connects to a DocumentDB cluster via DOCUMENTDB_URI, seeds an idempotent dataset, creates indexes, attempts a server-side $graphLookup and falls back to a bounded client-side traversal, applies AML heuristics, and emits structured Pydantic SuspiciousChain objects. The build ran seed and detector against the live cluster in this environment. Important gaps: the typology matching was not implemented as server-side aggregation stages (the detection logic runs in Python), a single shared MongoClient singleton was not implemented, tests require a live cluster (no offline unit tests), and some dependency versions are not fully pinned. Also, external documentation was not searchable from this run (documentation_search_available=false), so many external best-practice checks could not be verified beyond the local code. See requirement_results, checks and doc_gaps for details and minimal fixes.
