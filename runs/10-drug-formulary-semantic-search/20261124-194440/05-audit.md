# 5. Best-practice audit: 10-drug-formulary-semantic-search

**Verdict: pass_with_findings** (10 followed, 7 violated, 1 not applicable, 2 not assessable)

The sample implements the core user-facing behavior: a FastAPI /formulary-search endpoint that embeds an input string and issues a $search/cosmosSearch aggregation returning the top-10 matches with searchScore. The repository reads secrets from environment variables, seeds data idempotently (upserts), and reuses a singleton MongoClient. However several important checklist and discovered-practice items were not implemented: the code does not use LlamaIndex for embeddings (it calls OpenAI directly), it does not create the vector index in code, it does not record embedding model metadata in documents, index creation/verification (explain) is omitted, conventional metadata indexes and retry/backoff logic are missing, and tests do not run without a live cluster. Many of these gaps are operational or documentation issues rather than functional bugs in the HTTP endpoint itself. See requirement_results, checks and doc_gaps for the actionable fixes and suggested priorities.
