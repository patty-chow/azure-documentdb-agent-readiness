# 5. Best-practice audit: 08-regulatory-compliance-rag-checker

**Verdict: pass_with_findings** (8 followed, 2 not assessable, 4 violated, 3 not applicable)

The sample is a small, working Python demo that seeds two collections (regulatory/internal policies), stores embeddings when an OpenAI key is present, exposes a CLI and FastAPI /analyze endpoint, and includes a LlamaIndex adapter example. Key gallery expectations are implemented (singleton client, .env.example, README, idempotent upserts, projection usage, returned similarity scores, unit test using mongomock). Shortcomings: the runtime uses client-side brute-force similarity instead of server-side cosmosSearch/$search vector queries; the sample does not run LlamaIndex as the runtime (only an adapter example); vector index creation was attempted but the MCP tool was disabled in verification and server-side index listing did not show the vector index; error handling for empty queries/embedding failures is minimal; some dependency pins are loose (openai unpinned). See detailed requirement-by-requirement results, practice checks and decisions below.
