## Notes

Discovery used the installed DocumentDB skills (connection, driver, vector-search, indexing, security, monitoring, data-modeling, local-deployment, full-text-search, high-availability, storage) and Microsoft Learn documentation pages discovered via queries (examples include the Python quickstart, security and vector-search docs). The repository sample includes a seed_noembed mode and client-side brute-force retrieval for a tiny dataset; production guidance recommends server-side vector indexes and $search/cosmosSearch queries instead.
