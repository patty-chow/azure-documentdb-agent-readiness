# 5. Best-practice audit: 17-seasonal-trend-spotter-agent

**Verdict: pass_with_findings** (8 followed, 6 violated, 3 not assessable)

The sample implements a Python LangChain-style agent that combines a DocumentDB aggregation and a pluggable web-search tool, seeds idempotent sample data, and produces a ranked list. Core functionality requested by the starter prompt is present (LangChain agent with two tools, server-side aggregation pipeline, web-search tool and signal combination). Several checklist and best-practice items are missing or only partly implemented (season-to-season delta computation, context-engineered prompt to the model, explicit TLS/retry settings, test harness, strict dependency pinning, /search error contract, and batching for large seed loads). Many DocumentDB best-practices are discoverable and were consulted; some guidance (driver-version recommendations, web-search timeout/backoff sizing, batch-size guidance, UTC date guidance) is either present but hard-to-find, or only prior knowledge and should be documented for agentic builders. See requirement_results, checks, decision_reviews and doc_gaps for details and minimal fixes.
