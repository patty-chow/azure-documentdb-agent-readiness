# 5. Best-practice audit: 16-subscription-billing-engine

**Verdict: pass_with_findings** (10 followed, 2 violated, 2 not assessable, 1 not applicable)

The sample implements the requested billing engine: Node.js + Mongoose models, an idempotent transactional charge flow, TTL entitlements, idempotency unique index, a singleton client and idempotent seed and index scripts. The builder exercised the sample against the live cluster (create-indexes, seed, test-charge) and verified indexes via the MCP tools. Findings: a few gallery-level expectations are incomplete (env example not exhaustive, driver version pinning, no offline unit tests, missing an explicit subscriptionId index creation despite a schema index and autoIndex:false), several small reliability/observability practices are not implemented (no bounded retries / backoff), and some implementation choices (autoIndex:false, retryWrites:false, pool sizing) were made without a logged decision. Several documentation gaps were found where public guidance or discoverability could be improved so agents won't misapply neighbouring-product guidance (DocumentDB vs Cosmos DB). See requirement_results, checks, decision_reviews and doc_gaps for details.
