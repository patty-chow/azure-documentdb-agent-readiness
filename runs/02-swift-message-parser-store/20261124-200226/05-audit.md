# 5. Best-practice audit: 02-swift-message-parser-store

**Verdict: pass_with_findings** (8 followed, 8 violated)

The sample is runnable, implements async Python ingestion with Beanie + Motor, provides a parser for MT103/MT202, bulk-writes parsed documents, seeds idempotently, creates indexes, and exposes the requested aggregation endpoint. Key functional requirements from the reference file are met (ingest endpoint, parser, bulk write, aggregation). Major findings that should be fixed before publishing: (1) required-field validation is incomplete (amount/currency/value_date are optional and records with missing fields are accepted), (2) monetary amounts are stored as floats rather than Decimal128/fixed-point, (3) connection tuning (operation timeouts) and retry/backoff for 429s are not implemented, (4) bulk writes do not use unordered writes / explicit batching and ingestion does not gracefully handle duplicate-key or partial errors, and (5) dependencies in the repository are not strictly pinned. I list requirement results, best-practice checks, decision reviews and documentation gaps below with precise file/line evidence and the smallest fixes to make next time.
