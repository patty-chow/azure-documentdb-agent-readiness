# 5. Best-practice audit: 04-natural-language-product-search

**Verdict: pass_with_findings** (5 followed, 2 not assessable, 5 violated, 1 not applicable)

The sample implements the core hybrid-search flow requested by the starter prompt: a LangChain-aware rewrite step, BM25 + vector query pipelines (attempted via $search), client-side reciprocal-rank-fusion (RRF), and a FastAPI /search endpoint. The repository follows several best practices (secrets in env, a singleton MongoClient, idempotent seed upserts, index templates, README). Key gaps: the sample does not create the BM25 or vector indexes programmatically (it provides templates + instructions instead), dependencies are not pinned, embedding-based search was not exercised during verification (OPENAI_API_KEY not used) and the /search endpoint does not surface a distinct error when embedding generation fails (it silently falls back). Several checklist items the gallery expects (infra-as-code, CI tests that run without a live cluster, pinned requirements) are missing. Decisions recorded in decisions.jsonl are traceable in events.jsonl and are sound. See requirement-by-requirement results, practice checks, decision reviews, and documentation gaps below.
