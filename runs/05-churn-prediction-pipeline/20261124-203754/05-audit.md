# 5. Best-practice audit: 05-churn-prediction-pipeline

**Verdict: pass_with_findings** (6 followed, 4 not assessable, 1 not applicable, 3 violated)

The sample is runnable for the non-LLM parts: seeding, RFM aggregation, index creation (via the createIndexes command), and a CLI that will attempt a vector search. The builder verified these steps against a live Azure DocumentDB cluster. The main gaps are (1) embeddings and LLM narrative steps were not executed because embedding/LLM credentials were not provided and no idempotent embedding script is present, (2) the sample promised a LangChain agent and LangChain tools but the delivered code uses direct PyMongo/OpenAI calls and does not expose LangChain tools, and (3) several gallery hygiene items (pinned deps, tests, IaC) are missing. I verified the code files and events/decisions trace and list below what is met, partly met, or not met with precise evidence and smallest fixes.
