## Where public sources contradict the model

### P05: For many DocumentDB quickstarts and for vector-index operations, set retryWrites=false in the connection string (driver-managed write retries are often disabled for DocumentDB vector-search operations).

- **The model believed:** Enable and rely on driver retryable reads/writes where available and implement additional idempotent-safe retries with exponential backoff for transient network/timeout errors (with jitter). (knowledge of `mongodb`)
- **The source says:** For many DocumentDB quickstarts and for vector-index operations, set retryWrites=false in the connection string (driver-managed write retries are often disabled for DocumentDB vector-search operations).
- **Source:** [Quickstart: Vector index with Python / Node / .NET (samples and notes)](https://learn.microsoft.com/azure/documentdb/quickstart-python-select-algorithm#create-the-algorithm-comparison-code)
