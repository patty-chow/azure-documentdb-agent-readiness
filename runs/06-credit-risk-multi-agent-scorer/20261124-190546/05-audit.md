# 5. Best-practice audit: 06-credit-risk-multi-agent-scorer

**Verdict: pass_with_findings** (5 followed, 5 violated)

The sample implements a working, small credit-scoring pipeline that reads applicants from an Azure DocumentDB cluster, computes a deterministic rule-based score, optionally calls an LLM (mockable), generates an explanation, and writes score+explanation back to the applicant document. Tests and the seed script run in the build environment. Key functional requirements from the reference file are implemented, but several gallery expectations and best-practices are incomplete: the code does not use LangChain as the prompt required, LLM calls are direct OpenAI SDK calls (not LangChain), there is no retry/backoff for transient DB faults, dependencies are not pinned, tests require a live DocumentDB instance (no offline/mock DB tests), and infrastructure-as-code for provisioning the cluster is missing. I list per-requirement results, reconciled practice checks, decision reviews, and documentation gaps with prioritized fixes below.
