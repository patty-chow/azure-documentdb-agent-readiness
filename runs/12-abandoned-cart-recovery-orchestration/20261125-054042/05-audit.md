# 5. Best-practice audit: 12-abandoned-cart-recovery-orchestration

**Verdict: pass_with_findings** (5 followed, 7 violated, 2 not applicable, 1 not assessable)

The sample implements the requested abandoned-cart orchestration and was exercised end-to-end against the provided cluster (seed + one run). Core flows are present and tested (LangChain copy-generation + channel adapter + recovery log writes). Most gallery hygiene items are present (README, .env.example, unit tests that mock the DB, package-lock.json). Key operational and best-practice gaps remain: the Mongo client enables retryable-writes (should be disabled for DocumentDB), the abandoned-cart query is not covered by a compound or partial index (only lastUpdated is indexed), the pipeline eagerly materialises all matches (toArray) rather than using a cursor/batching strategy, and the seed script is idempotent but does not create/await indexes. I list line-level evidence for each reference requirement, a set of practice checks reconciled with discovered guidance, decision reviews for all recorded decisions, and documentation/tooling gaps the product team should address so agents and builders can reliably produce correct samples next time.
