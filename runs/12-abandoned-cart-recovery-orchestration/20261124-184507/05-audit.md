# 5. Best-practice audit: 12-abandoned-cart-recovery-orchestration

**Verdict: pass_with_findings** (7 followed, 6 violated, 1 not applicable)

The sample implements the requested abandoned-cart orchestration end-to-end: it queries Azure DocumentDB for carts abandoned >2 hours, generates personalized copy (LLM when an API key is present; fallback stub otherwise), routes by customer preference to email/SMS stubs, and logs outcomes back to DocumentDB. Important correctness and hygiene practices are present (singleton MongoClient, idempotent seeding, .env.example, README, package-lock). The main shortcomings are (1) the builder did not install or use the LangChain JS library despite the starter prompt requesting a LangChain pipeline (functionality is present but not LangChain-native), (2) one index choice does not match the query shape (risk of COLLSCAN / poor performance), (3) no unit tests that run without a live cluster, and (4) some operational best-practices (retries, explain checks, capped delivery log) were not implemented. Several documentation / discoverability gaps (LLM defaults, LangChain version guidance, embedding-dimension guidance for vector indexes, guidance for offline tests and graceful shutdown examples) would reduce an agent's ability to produce the intended sample without human choices. See details below.
