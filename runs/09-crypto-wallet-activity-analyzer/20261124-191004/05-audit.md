# 5. Best-practice audit: 09-crypto-wallet-activity-analyzer

**Verdict: pass_with_findings** (23 followed, 2 not assessable, 3 violated)

The sample is runnable, connects to a live Azure DocumentDB cluster (DOCUMENTDB_URI), seeds idempotent demo transactions, creates the compound index {wallet_address:1, timestamp:1}, runs the server-side aggregation grouping by day, computes daily totals and counts, detects outliers (z-score) and returns a plain-language summary (local fallback or optional OpenAI). Key build choices (singleton client, serverSelectionTimeoutMS, index name) were logged and verified with the DocumentDB MCP explain/list-index tools. Major gaps: the builder did not implement the requested LangChain 'agent' and did not move statistical outlier detection into the DocumentDB aggregation tool as the starter prompt asked; transient-retry handling and bulk batched seeding are missing; dependencies are ranged not fully pinned; there are no offline unit tests; infrastructure-as-code for cluster provisioning is absent. These shortcomings do not make the sample incorrect or insecure, but they are practical and discoverability gaps for the product team to consider.
