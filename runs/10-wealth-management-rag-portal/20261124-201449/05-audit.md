# 5. Best-practice audit: 10-wealth-management-rag-portal

**Verdict: pass_with_findings** (16 followed, 3 violated, 5 not applicable, 2 not assessable)

The sample implements the requested RAG flow: research docs are seeded with embeddings, embeddings are stored on documents, a cosmosSearch vector index is created, the agent fetches portfolio context, combines it with retrieved research, and persists per-client memory. Tests run without a live cluster, env-based secrets are present, and the code uses a single MongoClient per process. Key gaps: (1) the sample does not implement a real LlamaIndex Retriever integration (it is LlamaIndex-friendly but falls back to direct prompts), (2) no explicit error handling for empty queries or embedding failures at the /query endpoint, (3) transient-fault retry logic is not implemented, (4) bulk seeding is per-document (not batched), and (5) infrastructure-as-code for the cluster is not included. These findings are mostly non-blocking for a demo but should be fixed before publishing to the gallery. The run used discoverable DocumentDB guidance (vector-search, indexing, connection) and the builder followed that guidance for index shape and dimensions (1536) and HNSW parameters.
