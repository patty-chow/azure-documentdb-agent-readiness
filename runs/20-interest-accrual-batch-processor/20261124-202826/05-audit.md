# 5. Best-practice audit: 20-interest-accrual-batch-processor

**Verdict: pass_with_findings** (8 followed, 8 violated)

The sample implements the requested daily accrual worker correctly: it uses Mongoose models for accounts and journals, streams active interest-bearing accounts with a cursor, computes a per-account daily accrual, and writes immutable per-account journal documents in unordered bulkWrite batches. The build also provided an idempotent seed, a README, a test for the accrual math, and index creation at startup. Shortcomings found are primarily operational/hardening items that the prompt left unspecified (env listing completeness, projection/lean for queries, cursor.batchSize, retry/backoff handling for transient errors, and the placement of index creation at deployment vs run-time). None of the omissions make the sample functionally incorrect as a demonstration, but several are important for production hardening and for agents that must follow documented best practices.
