# 5. Best-practice audit: 17-esg-scoring-pipeline

**Verdict: pass_with_findings** (5 violated, 10 followed, 3 not applicable, 3 not assessable)

The sample is runnable, the core pipeline (seed → process → aggregate) is implemented and tested with deterministic fallbacks. Key best practices (singleton client, secrets in env, idempotent seeding, storing embeddings as numeric arrays, aggregation pipeline) are present. The build could not create a server-side cosmosSearch vector index because the MCP/create-index tool was disabled in this environment; server-side $search queries were therefore not verified and no /search endpoint was added. Several gallery-level items (server-side index creation automation, documented vector-index tuning, storing embedding model metadata on each document, an explicit /search API that returns similarity and handles empty queries, and an IaC template) are missing or only partly implemented. The verdict is pass_with_findings because the sample works and tests pass, but important production-level features and automation around vector index creation and semantic-search usage are incomplete or blocked by tool_unavailable during verification.
