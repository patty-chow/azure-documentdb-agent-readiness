# 5. Best-practice audit: 04-regulatory-reporting-orchestration

**Verdict: pass_with_findings** (10 followed, 6 violated, 5 not assessable, 1 not applicable)

The sample implements a runnable Python orchestration that extracts from multiple collections, validates, formats a filing, and records workflow-run documents in Azure DocumentDB. Unit tests run with mongomock and an end-to-end run against the live cluster was exercised by the builder. Findings: (1) LangChain itself was not wired into the orchestrator (the sample uses simple Python agent classes and an optional agents.py that references LangChain), (2) .env.example and the code disagree on a model environment variable name (MODEL_NAME vs CHAT_MODEL), (3) vector / search features and vector-index creation were explicitly omitted, and (4) the seed script is idempotent for data but does not create the indexes (index creation lives in the orchestrator). These are correctable; none of the omissions made the sample fail to run for the scenario demonstrated, but they leave gaps the gallery should close for uniform developer experience and discoverability.
