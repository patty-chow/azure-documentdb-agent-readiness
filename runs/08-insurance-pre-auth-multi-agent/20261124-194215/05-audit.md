# 5. Best-practice audit: 08-insurance-pre-auth-multi-agent

**Verdict: pass_with_findings** (7 followed, 8 violated, 3 not applicable, 3 not assessable)

The sample implements the requested multi-agent orchestration in Node.js: an orchestrator, a medical-review agent, and an insurer-comms agent that read and write to Azure DocumentDB. It runs end-to-end against the live cluster using a DOCUMENTDB_URI env var and includes an idempotent seed script, offline unit tests, and a README. Important gaps and findings: (1) the repository does not use the LangChain Node.js library even though the prompt asked for a 'LangChain' multi-agent setup (the sample uses a lightweight, LangChain-inspired approach); (2) the criteria query (by procedureCode) has no supporting index created by the seed script (COLLSCAN risk); (3) no retry/exponential-backoff logic is implemented for transient/429 errors; (4) IaC (Bicep/Terraform) for DocumentDB mongoClusters is not provided (intentional given run policy); (5) .env.example omits a few runtime env names (PREAUTH_ID, PORT) and the repository does not expose an embedding-model env even though earlier decisions recorded one. See requirement_results and checks for line-cited evidence and minimal fixes to get each requirement met next time.
