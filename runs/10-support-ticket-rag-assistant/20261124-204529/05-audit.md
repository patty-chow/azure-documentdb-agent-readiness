# 5. Best-practice audit: 10-support-ticket-rag-assistant

**Verdict: pass_with_findings** (9 followed, 5 violated, 1 not assessable)

The sample implements a working Python RAG flow that seeds a DocumentDB collection, populates embeddings (deterministic pseudo-embeddings by default), creates a cosmosSearch vector index (HNSW, 1536 dims), runs $search/cosmosSearch k-NN retrieval for top-5, injects the retrieved items into a concise prompt, and returns a suggested resolution. The main functional gaps are: the builder removed the requested LlamaIndex dependency (llama-index) due to environment/package issues, some production best-practices from the agent skills were not followed (no connection pool tuning, no retries, seed uses per-document upserts instead of bulk writes), the seed script does not create the vector index (index creation is a separate script), unit tests require a live cluster (no mocks), and the README lacks guidance for index tuning at scale. See requirement_results and checks for line-level evidence and smallest-fix recommendations.
