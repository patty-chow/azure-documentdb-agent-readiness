# 5. Best-practice audit: 11-preference-center-consent-store

**Verdict: pass_with_findings** (11 followed, 6 violated)

The sample implements the requested FastAPI + Beanie consent store, includes an idempotent seed script that was run and verified against the live Azure DocumentDB cluster, and creates a TTL index. Key features (endpoints, Beanie Document models, history array, consentVersion, TTL index and retention field population, environment-driven connection string, pinned requirements, README, .env.example) are present. Several important best-practice gaps remain (non-atomic read-modify-write updates instead of atomic $push/$set updates, no connection-pool tuning, Motor vs PyMongo compatibility causing a runtime mismatch risk, unit tests that trigger DB startup and therefore cannot run reliably without mocking, and no infrastructure-as-code). These do not make the sample unusable (the seed and verification succeeded), but they are significant findings for correctness/reliability and for agentic reproducibility. See requirement_results, checks and doc_gaps for details and recommended fixes.
