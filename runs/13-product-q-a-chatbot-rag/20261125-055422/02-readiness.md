# 2. Build readiness: 13-product-q-a-chatbot-rag

**Verdict: ready_with_gaps**

- Ready to start: Python, pip, node/npx, Docker, az (signed in), the documentdb MCP server (connection_profile default), and the DocumentDB agent skills are installed and available.
- Many cold answers were inaccurate (they described Cosmos DB (RU) or older names) — the builder must use the Microsoft.DocumentDB/mongoClusters resource type and az documentdb CLI group, not databaseAccounts/az cosmosdb.
- DocumentDB provides native vector indexes (vector-diskann, vector-hnsw, vector-ivf) and a cosmosSearch operator for $search; use those rather than Azure Cognitive Search for RAG vectors.
- Authentication supports both native (SCRAM) credentials and Microsoft Entra ID (MONGODB-OIDC); connection strings use mongodb+srv and tls=true to the *.mongocluster.cosmos.azure.com host(s).
- Missing accelerators (DocumentDB Agent Kit package) and mongosh on PATH slow debugging and convenience checks; they are not blockers but are recommended to add.
- Open decisions remain (embedding model & dimensions, LLM choice/provider, sample data) and must be chosen before index creation; document these choices in README/.env.example.
