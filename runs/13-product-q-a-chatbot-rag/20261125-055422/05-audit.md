# 5. Best-practice audit: 13-product-q-a-chatbot-rag

**Verdict: pass_with_findings** (4 followed, 6 violated, 2 not assessable)

The sample implements a working, minimal CLI RAG demo that seeds product documents and chunk documents into the live Azure DocumentDB database, retrieves top-5 chunks, and generates grounded answers (or a fallback) in an interactive REPL. Core engineering choices (singleton MongoClient, env-driven config, pinned dependencies, unit test) are present. However, the repository does not actually create or verify a cosmosSearch vector index (the MCP create_index call failed due to management tools being disabled), LlamaIndex was removed from requirements (so the sample is not implemented using LlamaIndex), embeddings were not computed in the verification run (OPENAI_API_KEY was not set), and several gallery checklist items (index creation automation, context-window token trimming, bulk ingestion optimization, infra-as-code) are incomplete or only partially addressed. The builder logged decisions for most major choices; a few in-code choices (vector index parameters attempted, text-search fallback) were not recorded as decisions and are reported in the audit trail. See Requirement Results, Practices checks and Doc Gaps below for actionable fixes and minimal edits to meet the full gallery checklist next time.
