# 5. Best-practice audit: 19-option-chain-data-store

**Verdict: pass_with_findings** (13 followed, 5 not assessable, 1 not applicable, 3 violated)

The sample implements the core requested functionality: a Python/FastAPI ingestion service that receives option-chain snapshots, performs unordered bulk writes (ordered=False), uses UpdateOne upserts, creates the compound index (underlying, expiry, strike), and exposes an endpoint to return a chain filtered by underlying+expiry and sorted by strike. Important additional gallery expectations are also implemented (env-based connection, .env.example, batched seed script, pinned dependencies, singleton MongoClient, README). Remaining findings: (1) no retry/backoff around bulk writes (reliability gap), (2) a small broken helper script (scripts/ensure_indexes.py imports a missing get_db), (3) unit tests could not be run in this environment due to a FastAPI / Pydantic import issue (environment/tooling), and (4) no IaC to provision a cluster. Several documentation gaps were also found where prior-knowledge recommendations have no public guidance. See Requirement Results, Practice Checks, Decision Reviews and Doc Gaps below.
