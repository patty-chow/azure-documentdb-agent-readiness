# 5. Best-practice audit: 20-store-locator-with-geospatial-search

**Verdict: pass_with_findings** (11 followed, 7 violated, 6 not applicable, 3 not assessable)

The sample implements the core requested functionality: a Node.js + Express + Mongoose service that stores GeoJSON Point locations, creates a 2dsphere index, exposes GET /nearby which runs a $geoNear aggregation and returns opening hours and stock. Seed, verify and README quickstart were provided and verified against the live Azure DocumentDB cluster. Findings are mostly documentation, hardening and a few best-practice gaps (retries, pagination, explicit connection options, production index build guidance, tests, and cleanup instructions). Several product-team best-practices are present and discoverable in the installed DocumentDB skills; two common Mongoose/MongoDB priors (autoIndex and lat/lon input validation) had no service-specific public guidance in the discovery step and remain gaps.
