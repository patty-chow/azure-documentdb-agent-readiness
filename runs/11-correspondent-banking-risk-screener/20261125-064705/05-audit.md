# 5. Best-practice audit: 11-correspondent-banking-risk-screener

**Verdict: pass_with_findings** (28 followed, 1 violated)

The sample implements the requested Python LangChain-style agent, seeds example correspondent/sanctions/adverse-media documents with embeddings, runs client-side similarity search, computes a risk score and returns matches plus a plain-language narrative. It is runnable locally (seed, tests, example run succeeded with deterministic embeddings when OPENAI_API_KEY was absent). Key gaps: the sample intentionally avoids creating a server-side vector index and therefore does not exercise $search / cosmosSearch vector queries or publish IaC for the managed DocumentDB cluster. Several documentation items (index creation syntax & parameters, recommended createIndex example, and index tuning guidance) are missing or left to the user; these are documented below as recommended fixes.
