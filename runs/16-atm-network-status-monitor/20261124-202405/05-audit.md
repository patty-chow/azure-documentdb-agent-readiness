The sample implements the core functionality the starter prompt asked for: a Node.js + Mongoose API that accepts heartbeats, writes them to Azure DocumentDB, opens a change stream, maintains per-ATM state, computes availability, and writes alert documents when availability falls below a configurable threshold.
