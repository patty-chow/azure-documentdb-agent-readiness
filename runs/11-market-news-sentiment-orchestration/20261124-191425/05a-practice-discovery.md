### P05: Set retryWrites=false in the MongoDB connection string for Azure DocumentDB and implement application-level retries with exponential backoff and idempotent writes instead of relying on driver-managed retryWrites.

- **The model believed:** Enable retryable writes and implement application-level retries with exponential backoff for transient network or rate-limited errors; make write operations idempotent when possible (e.g., upsert with a unique client-generated id). (knowledge of `mongodb`)
