- **Source:** [Azure Cosmos DB feature support (MongoDB) / aggregation pipeline pages](https://learn.microsoft.com/azure/cosmos-db/mongodb/feature-support-70#aggregation-pipeline)

## Notes

I inspected the app and loaded multiple installed skills (documentdb-*) plus Microsoft Learn pages. Most prior beliefs from general MongoDB and Cosmos guidance were confirmed by Azure DocumentDB docs or installed skills. Key contradictions: (1) bulk unordered writes can be disallowed when the server-side retryable-writes capability is enabled — Azure docs explicitly warn unordered bulk writes aren't supported in that mode; (2) client writeConcern is ignored / mapped by the service, so don't rely on setting custom client writeConcern for durability; (3) the $bucket/$bucketAuto aggregation stages are not supported in many MongoDB API server versions according to the Azure feature-support pages, so pipelines relying on them may not run on Azure DocumentDB; use alternative bucketing or materialized/stream approaches. Where guidance came from an installed skill I listed the skill name in how_found; where it came from Microsoft Learn I used the search or query that found the page and included the exact URL from the tool result.
