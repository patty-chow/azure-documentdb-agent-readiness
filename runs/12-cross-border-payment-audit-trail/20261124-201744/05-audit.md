# 5. Best-practice audit: 12-cross-border-payment-audit-trail

**Verdict: pass_with_findings** (12 followed, 7 violated, 2 not applicable, 1 not assessable)

The sample implements the requested Node.js + Mongoose immutable per-stage audit trail, timeline aggregation, idempotent seed, and application-layer immutability guards. It reads the connection string from DOCUMENTDB_URI and reuses a single Mongoose client. The builder attempted to create and verify a compound index via the DocumentDB MCP tool but the MCP management tool calls failed (management tools are disabled in this environment), and explain() reported a COLLSCAN for the small dataset. Remaining findings are largely around index creation/verification, missing offline unit-test fixtures, and service-hardening guidance (retries, explicit TLS validation and least-privilege guidance). None of the findings make the sample unusable, but they should be addressed before gallery publication.
