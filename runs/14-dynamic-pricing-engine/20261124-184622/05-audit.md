# 5. Best-practice audit: 14-dynamic-pricing-engine

**Verdict: pass_with_findings** (10 followed, 4 violated, 1 not applicable, 1 not assessable)

The sample implements the core dynamic-pricing behaviour: three DocumentDB-backed query tools (competitor prices, demand metrics via an aggregation pipeline, margin rules), an LLM prompt that requests step-by-step reasoning, deterministic fallback pricing, and an atomic find_one_and_update to persist the recommended price. Key infra and hygiene pieces exist (singleton MongoClient, idempotent seed, .env.example, README). Shortcomings that matter to publishability and long-term correctness: the builder did not deliver a LangChain initialize_agent-based agent (switched to a lightweight orchestration because ChatOpenAI imports failed in this environment), dependencies are not pinned, optimistic concurrency and retry/backoff handling are not implemented, projections and TTL indexing are missing, and there are no unit tests that run without a live cluster. See requirement_results and checks for file/line evidence and minimal fixes.
