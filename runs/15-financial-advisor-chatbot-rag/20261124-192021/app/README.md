DocumentDB Financial Advisor RAG Sample

This sample demonstrates a Node.js retrieval-augmented generation (RAG) agent that:
- stores short financial knowledge articles in an Azure DocumentDB `knowledge` collection
- seeds each document with an embedding vector (deterministic local embeddings by default)
- retrieves relevant documents by cosine similarity and combines them with a mocked portfolio tool
- preserves conversation history (simple in-memory agent memory) so follow-ups resolve in context

Prerequisites
- Node.js 24+ and npm
- An Azure DocumentDB cluster reachable from this machine. Set DOCUMENTDB_URI in your environment.
- (Optional) OPENAI_API_KEY to generate embeddings from OpenAI; if unset the sample uses deterministic local embeddings.

Quick start
1. Install dependencies
   npm install

2. Set environment variables (example in .env.example)

3. Seed the sample data (idempotent)
   npm run seed

4. Run the demo conversation
   npm run demo

Files
- src/db.js — MongoDB client (singleton)
- src/seed.js — idempotent seed script to create `knowledge` collection and insert sample articles with embeddings
- src/agent.js — simple RAG agent: memory, retrieval, portfolio tool, answer composition
- src/run_demo.js — runs an end-to-end example conversation (initial question + follow-up)

Notes on indexes
This sample seeds documents but does not create a DocumentDB vector index automatically. For production or realistic vector search using DocumentDB's `cosmosSearch` (DiskANN/HNSW/IVF), create a vector index on the `embedding` field with the matching dimension (1536) and similarity `COS` as recommended by the DocumentDB vector-search guidance. You can create an index using the DocumentDB MCP server or the Azure CLI per your environment's tooling.

Security
- Never commit your DOCUMENTDB_URI or API keys. Use environment variables.
