# 5. Best-practice audit: 05-shopping-cart-with-real-time-inventory

**Verdict: pass_with_findings** (16 followed, 3 violated, 1 not applicable)

The sample implements the requested Node.js + Mongoose cart service and demonstrates multi-document transactions, optimistic concurrency and clear OutOfStock errors. Core functional requirements are met and the builder verified the code and indexes against a live Azure DocumentDB cluster. Findings: missing search endpoints (the sample has no /search), no offline unit tests, no infrastructure-as-code for cluster provisioning in the repo, and a few observability/verification practices (use of explain()) were not followed. Several public-best-practice items were discoverable and used (connection-from-env, TLS, single client reuse, transactions, retries, conditional update), but a small set of documentation/kit gaps remain (notably explicit guidance and copy-paste examples for Mongoose optimistic-concurrency handling on DocumentDB, vector-index createIndex snippets for Node, and a clearer billing note distinguishing vCore DocumentDB from RU-based Cosmos DB).
