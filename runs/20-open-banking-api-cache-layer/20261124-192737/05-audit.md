# 5. Best-practice audit: 20-open-banking-api-cache-layer

**Verdict: pass_with_findings** (8 followed, 3 violated, 1 not assessable, 5 not applicable)

The sample implements the requested Node.js Mongoose stale-while-revalidate cache against Azure DocumentDB and was verified against the live cluster. The core functionality (cache lookup, per-document TTL index, freshness checks, stale-while-revalidate background refresh, and a reusable client) is present and exercised by the demo. Several gallery checklist items and best-practice recommendations were only partially implemented or omitted (pinned driver version, explicit index creation in the seed flow, unit tests that run without a live cluster, dependency pinning format, and optional infra IaC). Several of those omissions stem from the starter prompt not asking for them; others are choices the builder made that differ from public quickstart guidance (Mongoose major version). The decisions recorded in decisions.jsonl are mostly supported by the build trace; a couple are either unverifiable or questionable versus public guidance (notably the Mongoose version choice). See findings below for per-requirement, per-practice, decision reviews, and recommended fixes and documentation gaps.
