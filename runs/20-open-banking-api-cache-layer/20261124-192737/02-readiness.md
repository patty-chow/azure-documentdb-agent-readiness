**Verdict: ready_with_gaps**

- Build can start: required tools are present (node, npx, documentdb MCP server, learn docs, relevant documentdb-* skills).
- Many cold answers were wrong because they described Azure Cosmos DB for MongoDB (RU) or older naming; the correct resource type for managed clusters is Microsoft.DocumentDB/mongoClusters and CLI uses az documentdb mongocluster.
