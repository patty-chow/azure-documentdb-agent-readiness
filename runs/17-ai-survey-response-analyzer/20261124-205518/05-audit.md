# 5. Best-practice audit: 17-ai-survey-response-analyzer

**Verdict: pass_with_findings** (11 followed, 4 violated, 1 not assessable)

The sample implements the core pipeline requested by the starter prompt: a Beanie Document model, an async enrichment loop that either calls OpenAI or a deterministic fallback, embeddings persisted to each document, and aggregation scripts that produce top-themes and sentiment distributions. The build pinned dependencies, included a runnable idempotent seed script, and provided a .env.example. The main gaps are: aggregation scripts use pymongo instead of Beanie as the reference requires; native vector index creation via the MCP tool failed (management tools disabled), so no vector index exists though embedding dimensions are enforced in code; no /search HTTP endpoint or unit tests are present; and README lacks concrete vector-index JSON / tuning guidance. The decisions recorded in decisions.jsonl are mostly supported by run evidence; one convenience choice (inserting the repo root on sys.path) is workable but flagged as a questionable practice in a published sample. See findings, practice checks and doc-gaps below.
