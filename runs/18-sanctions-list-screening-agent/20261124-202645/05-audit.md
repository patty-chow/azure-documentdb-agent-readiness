# 5. Best-practice audit: 18-sanctions-list-screening-agent

**Verdict: pass_with_findings** (6 followed, 4 violated, 1 not assessable)

The sample implements the screening flow end-to-end: seeding, storing embeddings on documents, creating a DocumentDB cosmosSearch vector index (via a PyMongo fallback), performing $search/cosmosSearch vector queries and $regex fuzzy matches, consolidating candidate sets, scoring, and returning a structured report via a FastAPI /screen endpoint. Unit tests pass locally and no secrets are committed. Findings: (1) the sample did not integrate LangChain even though the starter prompt asked for a 'LangChain agent' (builder omission), (2) the app issues unprefiltered regex queries with no text/search index (risk of collection scans), (3) no retry/backoff or batching logic for writes/remote calls, (4) index-creation and index-parameter tuning are present but README lacks guidance for scaling, and (5) infra-as-code for provisioning the DocumentDB cluster is missing. I list line-level evidence, the smallest fixes, a reconciliation of checklist vs discovered public guidance, decision reviews, and documentation gaps the product team should address.
