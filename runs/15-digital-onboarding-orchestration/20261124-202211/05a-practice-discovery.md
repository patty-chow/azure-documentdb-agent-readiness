- **The model believed:** Create a single Motor client (MotorClient) at app startup and reuse it everywhere (do not create a new client per request); close it on shutdown. (knowledge of `general`)
- **The source says:** Create a single AsyncMongoClient at application startup and reuse it across the process instead of creating a client per request; Motor is deprecated for new Python async code in favor of PyMongo's AsyncMongoClient.
- **Source:** [documentdb-connection](https://github.com/Azure/documentdb-agent-kit/blob/main/skills/connection/SKILL.md)
