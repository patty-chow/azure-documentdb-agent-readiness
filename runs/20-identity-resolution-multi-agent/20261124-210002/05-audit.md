# 5. Best-practice audit: 20-identity-resolution-multi-agent

**Verdict: pass_with_findings** (6 followed, 4 violated, 1 not applicable)

The sample implements the multi-agent identity-resolution flow, seeds synthetic data, creates an HNSW vector index, and runs an end-to-end orchestrator that writes golden records and audit entries to the provided Azure DocumentDB database. Key functionality exists and unit tests that do not require a live cluster pass. Shortcomings: the builder did not use LangChain for the agents (LLM-assisted scoring and agent wrappers are absent), some operational best practices are omitted (connection options / TLS settings, retries/backoff, pinned dependencies, and explicit IaC for provisioning). The app hardcodes the embedding dimension (1536) without runtime verification that it matches a chosen embedding model, and README lacks clean-up and some guidance for index tuning. Many of these gaps were anticipated by the readiness review; some held up, others were mitigated by safe fallbacks (synthetic embeddings, motor fallback when Beanie init fails). See requirement_results, checks and doc_gaps below for details and recommended minimal fixes.
