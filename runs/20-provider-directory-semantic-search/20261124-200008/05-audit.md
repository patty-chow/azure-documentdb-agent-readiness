# 5. Best-practice audit: 20-provider-directory-semantic-search

**Verdict: pass_with_findings** (15 followed, 6 violated, 2 not applicable, 1 not assessable)

The sample implements the requested provider-directory semantic search and runs successfully in this environment: seeded documents, created a cosmosSearch vector-hnsw index (1536 dims), runs vector queries against the live cluster, and unit tests ran offline. Major functional behaviors are present: a single MongoClient is reused, embeddings are stored per-document, /find-provider performs a $search/cosmosSearch vector query and returns ranked results including a numeric score. Key gaps: the builder removed LlamaIndex/OpenAI from runtime requirements (fallback embeddings are used) because pip dependency-resolution failed in this environment; there is no structured pre-filtering for specialty/language/insurance before vector search; no retry/backoff logic for transient DB errors or throttling; vector-index and query tuning guidance is not documented in README; and infrastructure-as-code for the cluster is absent. The report below lists per-reference-requirement results, practice checks (reconciling discovered guidance), decision reviews, and recommended documentation/tooling gaps for the product team.
